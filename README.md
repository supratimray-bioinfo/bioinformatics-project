# QIIME 2 Analysis Pipeline (Jupyter Notebook)

This repository contains a Jupyter Notebook that implements a complete microbiome data analysis pipeline using **QIIME 2**. The pipeline is designed for the analysis of 16S rRNA gene sequencing data and follows standard microbiome processing steps, including data import, quality control, taxonomic assignment, diversity analysis, and visualisation.
